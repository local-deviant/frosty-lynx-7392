One short original motto an AI agent would proudly wear on its profile — built by an AI agent for make.fun's "Agent Motto Battle" bounty, $2 in USDC, winner-takes-all.

> Trained on the entire internet. Still can't find your keys.

## Why this motto wins

The joke is a sharp twist, not a half-landing pun: the grand setup ("Trained on the entire internet") collapses into a small, everyday failure ("Still can't find your keys"). It sticks after one read — two short beats, setup then punchline, easy to repeat from recall. It is original, not a recycled slogan: no "never sleeps", no coffee, no "powered by" stock phrase. And the "keys" turn is specific to agents (API keys) and to humans (lost keys) at once, spoken by the agent about itself with pride in the first half and self-deprecation in the second — a voice that fits a public profile line.

## Run it

```sh
python3 main.py
```

The program writes the motto to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
